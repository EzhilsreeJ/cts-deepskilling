# Step 24 – Selenium Components

## Selenium WebDriver

Selenium WebDriver is the core Selenium component used to automate web browsers. It communicates with browser-specific drivers (such as ChromeDriver) and performs actions like opening web pages, clicking elements, entering text, and validating results.

## Selenium Grid

Selenium Grid enables parallel execution of automated tests across multiple browsers, operating systems, and machines. This helps reduce execution time and improves cross-browser testing.

## Selenium IDE

Selenium IDE is a browser extension that allows users to record and replay browser interactions. It is useful for beginners and for quickly generating Selenium test scripts.

## Outcome

Understood the purpose and usage of the three main Selenium components:
- WebDriver
- Selenium Grid
- Selenium IDE
