# Week 5 & 6 – QA Concepts & Test Automation (Selenium Basics)

## Overview

This folder contains my solutions for **Week 5 and Week 6** of the **Cognizant Digital Nurture 5.0 – Python Full Stack Engineer Track**.

The focus of these weeks is on **Software Testing**, **Quality Assurance**, and **Selenium Test Automation**. The hands-on exercises progress from QA fundamentals to building a maintainable Selenium automation framework using the **Page Object Model (POM)**.

---

## Learning Objectives

- Understand Software Testing Fundamentals
- Learn QA Concepts and Testing Lifecycle
- Understand SDLC, TDLC and Agile QA
- Learn Selenium WebDriver Architecture
- Automate Browser Interactions
- Work with Selenium Locators
- Implement Explicit Waits
- Build Automated Test Suites using PyTest
- Generate HTML Test Reports
- Implement Page Object Model (POM)
