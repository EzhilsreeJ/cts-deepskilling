# Week 3 - Frontend Development

## Overview

This repository contains the solutions for Week 3 Frontend Development hands-on exercises from the Cognizant Digital Nurture Python FSE program. The exercises focus on modern JavaScript (ES6+), DOM manipulation, asynchronous programming, Fetch API, Axios, and API integration.

**Topics Covered**

- Forms and Tables
- CSS Styling
- Flexbox
- Responsive Layout
