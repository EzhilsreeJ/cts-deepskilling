# Cognizant Digital Nurture 5.0 – Database Integration (FSE)

## Project Overview

This project contains all the Database Integration hands-on exercises (1 to 7) done as part of the Cognizant Digital Nurture 5.0 Full Stack Engineering program.

It includes working with:
- SQL (database design, queries, joins, procedures, transactions)
- Query optimization techniques
- MongoDB (NoSQL operations)
- Python ORM using SQLAlchemy
- Database migration using Alembic

Each hands-on focuses on real-world database concepts and how they are used in backend development.

- Subqueries

- Transaction handling (commit, rollback, savepoint)

### Hands-On 4 – Query Optimization
- Used EXPLAIN to analyze queries
- Created indexes

### Hands-On 5 – MongoDB
- Created database and collections
- Inserted and managed documents
- CRUD operations

### Hands-On 6 – ORM with SQLAlchemy
