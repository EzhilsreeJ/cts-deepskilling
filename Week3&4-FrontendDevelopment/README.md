# Week 3 & 4 – Frontend Development

## Overview

Week 3 and Week 4 of the **Cognizant Digital Nurture 5.0 – Python Full Stack Engineer Deep Skilling Program** focus on **Frontend Development**.

A complete **Student Portal** application is developed progressively across ten hands-on exercises using **HTML5, CSS3, JavaScript, React, Angular, and Vue.js**. The program covers modern frontend development concepts, responsive design, asynchronous programming, routing, state management, accessibility, and API integration.

## Learning Outcomes

By the end of Weeks 3 and 4, I was able to:

- Build responsive web applications using HTML5, CSS3, and JavaScript.
- Apply ES6+ features for dynamic frontend development.
- Manipulate the DOM and handle user interactions effectively.
- Consume REST APIs using Fetch API and Axios.
- Develop Single Page Applications using React.
- Implement client-side routing using React Router and Vue Router.
- Manage application state using Context API, Redux Toolkit, NgRx, and Pinia.
- Build Angular applications using Components, Services, Dependency Injection, Routing, and Reactive Forms.
- Develop Vue.js applications using the Composition API and Pinia.
- Improve web accessibility using semantic HTML, ARIA attributes, keyboard navigation, and WCAG guidelines.
- Verify accessibility using Lighthouse and ensure cross-browser compatibility.
- Build a centralized API service layer using Axios with request and response interceptors.
- Apply advanced frontend architecture and state management patterns across React, Angular, and Vue.
