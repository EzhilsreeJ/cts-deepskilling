# Week 2 – Python Backend Frameworks

## Overview

Week 2 of the **Cognizant Digital Nurture 5.0 – Python Full Stack Engineer Deep Skilling Program** focuses on backend application development using Python web frameworks.

This week provides practical experience in developing RESTful APIs, implementing CRUD operations, integrating databases, authentication, request validation, and understanding modern backend architectures using **Django**, **Flask**, and **FastAPI**.

> **Note:** The **Unit Testing** module (PyTest, unittest, Jest, Mocha, Mocking, Test-Driven Development, and Code Coverage), which is also part of the official Week 2 schedule, has already been completed and documented under **Week 1** to avoid duplication.

## Module Covered

### Python Backend Frameworks

The module focuses on developing backend applications using three widely used Python frameworks:

- Django
- Flask
- FastAPI

## Objectives

The objectives of this module are to:

- Understand Python backend frameworks.
- Develop RESTful APIs.
- Perform CRUD operations.
- Work with ORM for database interaction.
- Integrate relational databases.
- Validate requests and responses.
- Implement authentication and authorization.
- Explore Microservices architecture.
- Build production-ready backend applications.
